CURTIS HARDY BRINKMAN — ONE-PAGE PORTFOLIO

Files
- index.html: page content and structure
- style.css: responsive styling
- script.js: mobile navigation and current footer year

How to use
1. Extract the ZIP file.
2. Open index.html in a browser to preview.
3. Upload index.html, style.css, and script.js to the same folder on your hosting account.

Notes
- Contact information and skills are based on the supplied resume images.
- The portfolio uses Google Fonts (Manrope and DM Sans), so an internet connection is needed for those fonts. It falls back to system sans-serif fonts if unavailable.
- Replace any contact details if they change.
